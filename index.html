Informática sin barreras

Aprendo y participo mediante el sonido y el teclado.

Bienvenida e instrucciones

En esta actividad aprenderás qué es un archivo, qué es una carpeta y para qué sirven algunos comandos de teclado. Puedes completar todas las actividades sin utilizar el ratón.

Para desplazarte entre botones y respuestas, pulsa Tabulador. Para retroceder, utiliza Mayúsculas y Tabulador. Pulsa Enter o Espacio para activar un botón. En las preguntas, utiliza las flechas para elegir una respuesta.

Si tu equipo tiene un lector de pantalla, podrás escuchar el contenido. También puedes usar el botón «Escuchar explicación», que utiliza la voz disponible en el navegador.

Lección 1. Archivos y carpetas

Un archivo es un elemento que almacena información, como un texto, una canción o una fotografía. Una carpeta permite organizar y reunir archivos. Por ejemplo, puedes crear una carpeta llamada «Tareas» y guardar allí tus documentos escolares. Para localizar información más fácilmente, conviene usar nombres claros y descriptivos.

Ejemplo: La carpeta «Tecnología» contiene el archivo «Actividad de informática.txt».

Lección 2. Atajos de teclado

Puedes utilizar combinaciones de teclas para trabajar sin ratón. Estos ejemplos corresponden a acciones comunes de Windows.

Control + C
Copiar un elemento seleccionado.
Control + V
Pegar el elemento copiado.
Control + S
Guardar un documento en muchas aplicaciones.
Alt + Tabulador
Cambiar entre ventanas abiertas.

Actividad interactiva. Demuestro lo aprendido

Responde tres preguntas. Cada respuesta se anunciará en texto y puede leerse con tu lector de pantalla. Puedes corregir tus respuestas antes de terminar.

Pregunta 1 de 3. ¿Para qué sirve una carpeta digital?
Pregunta 2 de 3. ¿Qué combinación permite copiar un elemento en Windows?
Pregunta 3 de 3. ¿Cuál es el nombre más descriptivo para un trabajo escolar?

Cierre y reflexión

Reflexiona: ¿cómo te ayuda organizar tus archivos? ¿Qué comando de teclado te gustaría practicar de nuevo?

El aprendizaje no depende de ver una pantalla, sino de contar con formas accesibles de acceder a la información y participar en las actividades.

Nota para docentes: Este es un prototipo de enseñanza y evaluación conceptual, no un simulador que manipule archivos reales. Para validar la accesibilidad deben realizarse pruebas con la alumna y con su lector de pantalla habitual.

Prototipo educativo de uso local. No requiere conexión a Internet y no recopila datos personales.
